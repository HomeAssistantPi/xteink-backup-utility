# XTEINK Pro 4 Utility

A Bash-based utility for the XTEINK Pro 4 (ESP32-S3). This tool allows you to backup/restore internal flash memory and manage MicroSD card data via a simple CLI interface.

## Features
- **Flash Backup/Restore:** One-click 16MB SPI Flash management.
- **SD Card Management:** Sync files or create RAW disk images using a PC card reader.
- **Auto-Dependency Check:** Detects and installs required tools on OpenSUSE, Debian, Arch, and Fedora.
- **MIT Licensed.**

## How to use
1. Clone this repo: `git clone https://github.com/YOUR_USERNAME/xteink-pro4-utility.git`
2. Run the script: `./xteink-manager.sh`
